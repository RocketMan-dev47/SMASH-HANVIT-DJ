# SMASH 한빛

대전한빛고등학교를 3D로 부수는 시험기간 스트레스 해소 게임입니다. 학교와 관계없는 비공식 팬 게임입니다.

[SMASH 대학교](https://hong-iron.github.io/SMASH/)에서 아이디어를 얻었고, 코드와 디자인은 처음부터 새로 만들었습니다.

## 실행하기

```
cd ~/Projects/SMASH-HANVIT
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. `index.html`을 더블클릭하면 안 열려요.
`data/campus.json`이 없으면 연습용 가상 학교가 나옵니다.

## 우리 학교 데이터 만들기

```
pip3 install pillow
python3 tools/fetch_campus.py find 한빛
python3 tools/fetch_campus.py build --way 번호
```

## 무기

| 키 | 무기 | 하는 일 |
| --- | --- | --- |
| 1 | 폭탄 | 누른 곳이 바로 터져요 |
| 2 | 배트 | 오렌지·블랙 거대 배트로 휘둘러요. 크기 S~XL 선택, 크게 맞으면 홈런! |
| 3 | 레이저 | 누른 채로 끌면 추진기로 떠 있는 테슬라 로드스터(스타맨 탑승)가 레이저를 쏴요 |
| 4 | 운석 | 우주(약 4 km 위)에서부터 불타며 떨어져요. 우주 어딘가에 작은 외계인이 있어요 |
| 5 | 지진 | 진도 Ⅳ~Ⅹ 선택. 진앙거리·진원거리·PS시·오모리 공식이 담긴 관측 카드와 지진계 기록이 떠요 |
| 6 | 산사태 | 비탈 위에서 바위가 굴러 내려와요 |
| 7 | 로켓 | HFV-1(실제 설계 치수)을 1.5 km 떨어진 HASA 발사장에서 쏴요. 2단은 분리 후 잠깐 관성 비행했다가 점화해요. SpaceX식 중계 화면, 1단은 발사탑 팔이 붙잡아 다시 써요 |
| 8 | 핵폭탄 | 위치 지정 패드(미니맵)나 화면에서 목표를 찍고 발사 → 3초 경보 뒤 떨어져 버섯구름이 피어올라요 (Enter로도 발사). KF-21이 날아와 투하해요 |

운석·핵폭탄·로켓은 카메라가 무기를 따라가요. 화면을 누르거나 Esc를 누르면 건너뛰고, 카메라 버튼으로 끌 수 있어요.
오른쪽 아래 나침반을 누르면 북쪽이 위로 오게 돌아가요.

다시 짓기를 누르면 화면이 옆으로 접히듯 넘어가며 새 학교가 펼쳐져요.

레이저를 고른 동안에는 화면 이동을 오른쪽 버튼(휴대폰은 두 손가락)으로 해요. N은 밤입니다.

## 설정 (config.json)

- `exams`: 시험 이름, 시작일 `date`, 마지막 날 `end`. 마지막 날 다음 날에는 운동장에서 불꽃놀이가 열려요. 미리 보려면 주소 끝에 `?fireworks`를 붙이세요.
- 시험 날짜: **지금 날짜는 예시**라서 학사일정으로 바꿔 주세요. 시험 2주 전부터 점수가 조금씩 올라요.
- `launchSite`: 로켓 발사장 위치 `[x, z]`(m). 비워 두면 학교에서 북동쪽 1.5 km에 생겨요.
- `golfCart`: `false`면 학교를 도는 골프 카트를 숨겨요.
- `showLogo`: `false`면 학교 로고를 숨겨요.
- `buildings`: 건물별 `name`, `levels`, `style`(`cream`, `white`, `brick`, `gray`, `glass`), `roof`, `hide`
- `bell`: 1등급과 미션 완료 때 울리는 종소리(Hz)

## 학년 대항 (전교 점수판)

설정이 없으면 이 기기 기록만 보여요. 친구들 점수를 모으려면 다음처럼 해요.

1. supabase.com에서 무료 프로젝트를 만들어요.
2. SQL Editor에 `supabase/schema.sql`을 붙여 넣고 Run을 눌러요.
3. Project Settings → API에서 Project URL과 공개 키(anon/publishable)를 `config.json`의 `supabaseUrl`, `supabaseKey`에 넣어요.

secret 키(service_role)는 절대 넣지 마세요.

## 휴대폰에서 하기

- 같은 와이파이: 아이맥에서 서버를 켠 채로 `ipconfig getifaddr en0`(안 나오면 `en1`)로 주소를 알아내고, 휴대폰에서 `http://그주소:8000`을 열어요.
- 어디서나: GitHub에 올리고 Settings → Pages에서 `main` / `(root)`로 켜면 `https://아이디.github.io/저장소이름/`으로 열려요.
- 한 손가락 끌기는 이동, 두 손가락은 돌리기·확대, 톡 누르면 공격이에요. 공유 버튼 → 홈 화면에 추가하면 앱처럼 꽉 찬 화면으로 열려요.

## 달력과 특별 에디션

왼쪽 아래 달력 버튼(또는 시험·수능 칩)을 누르면 달력이 열리고, 날짜를 골라 그날로 이동할 수 있어요.

- 시험이 끝난 다음 날: 운동장 불꽃놀이
- 12월 24·25일: 크리스마스 에디션(건물 조명과 지붕 눈, 트리, 루돌프 썰매, 선물상자 폭탄, 트리 로켓)
- 수능 날: 수능 응원 에디션
- 주소 끝에 `?xmas`나 `?fireworks`를 붙이면 바로 미리 볼 수 있어요.
- `suneung`(수능 날짜 목록), `anniversaries`(`[{"name": "개교기념일", "date": "MM-DD"}]`)를 config.json에 넣을 수 있어요.

별 모양 버튼은 오늘의 학습운세예요. 누를 때마다 행운의 과목·장소·아이템과 응원 한마디가 새로 나와요.

## 빠진 건물 그려 넣기 (배치 도우미)

주소를 `localhost:8000/?edit`로 열면 오른쪽에 배치 도우미가 떠요.

1. 건물 모서리를 땅에서 차례로 눌러요(3개 이상).
2. 이름·층수·외벽을 고르고 "건물로 저장"을 눌러요.
3. 국기게양대는 그 자리를 한 번 누른 뒤 "마지막 점에 국기게양대"를 눌러요.
4. "복사하기"를 누르고 config.json의 `"buildings"` 바로 위에 붙여 넣은 뒤 새로고침해요.

## 인터넷 링크로 열기 (GitHub Pages)

터미널 없이 누구나 링크로 열 수 있게 하려면 GitHub에 올리고 Settings → Pages에서 `main` / `(root)`를 고르세요.
주소는 `https://아이디.github.io/저장소이름/`이에요. 고친 뒤에는 `git add . && git commit -m "업데이트" && git push`만 하면 1~2분 뒤 반영돼요.

## 숨은 재미

- 학교 고양이: 흰 고양이 가족(새끼 3마리)과 치즈 고양이. 누르면 쓰다듬어요. 폭발이 나면 도망가고 절대 다치지 않아요.
- 매점(HV STORE): 본관 1층 간판 근처를 터뜨리면 바나나우유·초코파이 잭팟.
- 시험 기간(시험 2주 전부터)에는 건물이 부서질 때 OMR 시험지가 흩날려요.
- 미래관(급식실)을 꾹 누르면 그날 급식 메뉴(나이스 교육정보 개방 포털).
- 실시간 대전 날씨(Open-Meteo): 비가 오면 게임에도 비가 와요. `"weather": false`로 끌 수 있어요.
- 공유 버튼: 인스타 스토리용 세로 기록 카드를 만들어요.

## 둘러보기 모드 · 택배 · 개발자 단축키

- 왼쪽 위 SMASH 스위치를 끄면 둘러보기 모드: 무기 대신 학교 연혁이 나오고, 건물을 누르면 시설 안내가 떠요.
- HASA 택배차는 매일 10:30, 15:30에 4분 동안 와요. SMASH 모드에서 누르면 로켓 배송!
- 개발자 전용: `Ctrl + Shift + D`로 택배차를 바로 불러요(맥도 Control 키).
- 버스 정류장(한빛고교)과 미래관은 꾹 누르면 정보가 나와요. 버스 노선은 config.json의 `bus.routes`에 `{"no": "번호", "interval": 분, "first": "06:00", "last": "22:30"}`로 넣어요.
- 달력: 나이스 학사일정이 자동으로 나오고, 수행평가 같은 내 일정을 추가할 수 있어요(이 기기에만 저장). 나이스 인증키가 있으면 `neis.key`에 넣으면 더 빨라요.

## 시간대 · 날씨 · 사진 · 배지 · 투어

- 달 버튼: 시간(실시간/새벽/낮/노을/밤)과 날씨(실시간/맑음/흐림/비/눈/안개)를 고를 수 있어요. 선택은 이 기기에 저장돼요.
- 사진 모드: UI가 사라지고 카메라가 천천히 돌아요. "저장"으로 PNG를 받아요.
- 배지: 24가지 도전 과제. 이 기기에 저장돼요.
- 둘러보기 모드의 "1인칭 투어": WASD(폰은 조이스틱)로 걷고, 끌어서 둘러봐요. 위쪽 건물 버튼으로 바로 이동해요.
- 학년 대항은 학기별 시즌(3~8월 1학기, 9~2월 2학기). 지난 시즌 우승 학년 깃발이 국기게양대 옆에 서요.
  Supabase를 쓰고 있다면 supabase/schema.sql 맨 아래 "시즌제" 부분을 SQL Editor에서 한 번 실행하세요.

## 타임캡슐 찾기 · 응원의 벽 · 생물 도감 · 종소리

- 게임 버튼(과녁): 학교 어딘가의 타임캡슐을 탐사 폭탄 6발로 찾아요. 터진 자리에 거리(m)가 색과 숫자로 남고, 7 m 안이면 성공.
- 와우관(3학년관)을 빠르게 여러 번 누르면(둘러보기 3번, SMASH 5번) 응원의 벽이 열려요. 욕설은 자동으로 막고, 신고하면 숨겨져요.
  모두가 같은 벽을 보려면 Supabase를 설정하고 supabase/schema.sql의 "응원의 벽" 부분을 실행하세요. 설정 전에는 이 기기에만 저장돼요.
- 생물 도감(책 버튼): 고양이 5마리, 개구리(연못·겨울잠), 사마귀(세심정 풀숲·늦여름~가을), 박쥐(밤·인재원 하늘),
  하늘다람쥐(밤·아주 드묾), 고라니·멧돼지(학교 뒤 깊은 산). 눌러서 발견하면 도감에 등록돼요.
- 종소리: 평일 실제 시각(시간대가 "실시간"일 때)에 맞춰 수업 시작·끝 종이 울려요(사람은 등장하지 않아요).
  교시 시간은 config.json의 `bell.periods`에 `[["1교시", "08:40", "09:30"], ...]`처럼 넣어 바꿀 수 있어요.

## 학교생활 메뉴 · 미션 컨트롤

- 가방 버튼(학교생활): 시간표, D-day, 분실물 지도, 응원의 벽, 눈사람 만들기.
  - 시간표: 학년·반을 고르면 나이스에서 그날 교시별 과목을 가져와요. 종이 울릴 때 과목도 알려 줘요.
  - D-day: 수능·시험은 자동, 내 D-day를 추가하고 ★로 왼쪽 위 칩에 고정해요.
  - 분실물 지도: 땅을 눌러 잃어버린/주운 위치를 핀으로 남겨요. 전화번호 같은 개인정보는 자동으로 지워요.
    모두가 같은 지도를 보려면 Supabase 설정 후 supabase/schema.sql의 "분실물 지도" 부분을 실행하세요.
  - 눈사람: 겨울·눈 오는 날·크리스마스에 땅을 끌어 눈덩이를 굴리고, 작은 눈덩이를 몸통 위에 놓으면 완성.
- 로켓을 쏘면 HASA 미션 컨트롤이 열려요: GO/NO-GO 점검, 퀸드라 톤 교신 로그, 고도·속도 그래프, 단별 상태등.

## HASA 관제센터(개발자용 텔레메트리)

- 게임에서 `Ctrl + Shift + H`(맥은 Control)를 누르면 `hasa.html`로 이동해요.
- 모으는 것: 무작위 세션 번호, 기기 종류, 화면 크기(100 단위), 쓴 무기·기능, 무너진 건물, 배지·도감, 점수, 오류, FPS.
  모으지 않는 것: 이름·학번·연락처·정확한 위치·입력한 글. 후원(하트) 카드에서 끌 수 있어요.
- "이 기기" 보기: 설정 없이 바로 이 브라우저의 기록을 볼 수 있어요.
- "서버(전체)" 보기: Supabase 설정 후 supabase/schema.sql의 "HASA 텔레메트리" 부분을 실행하고,
  맨 아래 주석의 관리자 키 줄을 내 키로 바꿔 한 번 실행하세요. 관제센터에서 그 키를 넣으면 전체 기록이 보여요.
  학생 기기는 기록을 쓰기만 하고, 읽기는 관리자 키가 있어야 돼요. 90일 지난 기록은 자동으로 지워져요.

## 태권도 · 햅틱 · 임무 패치 배지 · 버튼 배치

- 태권도(무기): 거대한 사범이 돌려차기·옆차기·내려찍기·뒤후려차기·뛰어옆차기를 차례로 써요. 쓸수록 흰→노랑→초록→파랑→빨강→검은 띠.
- 햅틱: 무기·버튼마다 다른 진동(안드로이드 크롬 등). 아이폰 사파리는 웹 진동을 지원하지 않아요. 달 버튼(설정)에서 끌 수 있어요.
- 배지 68개: 우주 임무 패치 디자인(브론즈·실버·골드·레전드). 연속 접속, 시간대, 홀인원 같은 어려운 조건 포함.
- 버튼 배치: 아래 왼쪽은 자주 쓰는 5개(다시 짓기·소리·설정·학교생활·⋯), 나머지는 ⋯ 메뉴. 작은 화면에선 버튼이 무기 바 위로 올라가요.

## 앱 보관함 · 블록 월드

- 넓은 PC 화면(가로 1440 이상)이 아니면 아래 버튼들이 앱 보관함 버튼 하나로 접혀요. 누르면 분류별 카드가 스프링 모션으로 펼쳐져요(아래로 쓸어내리거나 바깥을 누르면 닫힘).
- 블록 월드(숨은 모드): HASA 택배차를 누를 때 방문마다 한 번, 8% 확률로 얻어요(config.json의 `blockChance`로 조절).
  얻은 기기에서만 앱 보관함(또는 ⋯ 메뉴)의 "블록 월드"로 켜고 끌 수 있어요. 개발자 테스트: `Ctrl + Shift + B`.
